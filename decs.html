CP models (X, D, C): Adj and Nei

The two encodings used in CpModels.java to generate, up to isomorphism, the simple graphs with a given degree sequence \(\mathit{deg} = (\mathit{deg}_0 \le \dots \le \mathit{deg}_{n-1})\): vertex \(i\) has degree \(\mathit{deg}_i\). Each constraint is given first as a formula, then as the Java (CP Optimizer) code that posts it. Vertices are indexed \(0..n-1\) as in the code; in the Nei model vertex \(i\) is written with the label \(i+1\), so that 0 can mean "empty slot". \(D = \max_i \mathit{deg}_i\) is the largest degree, and \(P = |\{(i,j) : i < j,\ \mathit{deg}_i = \mathit{deg}_j\}|\) the number of equal-degree pairs (\(P = n(n-1)/2\) for a regular sequence).

Size = number of constraints posted by the code. Arity = number of decision variables in the scope of one constraint (for expressions such as count, the variables they read).

1. Adjacency model (Adj)

1.1 Variables X

$$X = \{\, M_{ij} \;:\; 0 \le i, j < n \,\}, \qquad M_{ij} = 1 \iff \{i,j\} \in E$$
|X| = \(n^2\) variables
IloIntVar[][] M = new IloIntVar[n][];
for (int i = 0; i < n; i++) {
    M[i] = cp.intVarArray(n, 0, 1);
    ...
}

1.2 Domains D

$$D(M_{ij}) = \{0, 1\}$$
|D| = 2 values per variable
cp.intVarArray(n, 0, 1)

1.3 Constraints C (base model, buildAdjacencyModel)

C1 — No self-loop (zero diagonal)

$$\forall i \in [0,n): \quad M_{ii} = 0$$
Size: \(n\) constraintsArity: 1
cp.add(cp.eq(M[i][i], 0));              // no self-loop

C2 — Degree

$$\forall i \in [0,n): \quad \sum_{j=0}^{n-1} M_{ij} = \mathit{deg}_i$$
Size: \(n\) constraintsArity: \(n\) (a whole row, diagonal included)
cp.addEq(cp.sum(M[i]), deg[i]);         // degree

C3 — Symmetry (undirected graph)

$$\forall\, 0 \le i < j < n: \quad M_{ij} = M_{ji}$$
Size: \(n(n-1)/2\) constraintsArity: 2
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        cp.add(cp.eq(M[i][j], M[j][i]));    // undirected
    }
}

1.4 Symmetry breaking

Notation: \(M_i^{\setminus\{i,j\}}\) is row \(i\) with columns \(i\) and \(j\) removed (without), and \(\operatorname{rev}(\cdot)\) reads a vector right to left (reverse). Posted only when \(n \ge 3\), and only for pairs of equal degree: with fixed degrees, only equal-degree vertices can swap labels, so ordering other pairs would lose graphs.

SB-RevLex — addOptRevLex

$$\forall\, 0 \le i < j < n,\ \mathit{deg}_i = \mathit{deg}_j: \quad \operatorname{rev}\!\big(M_i^{\setminus\{i,j\}}\big) \;\le_{lex}\; \operatorname{rev}\!\big(M_j^{\setminus\{i,j\}}\big)$$
Size: \(P\) lexicographic constraints (\(n\ge 3\))Arity: \(2(n-2)\): two vectors of length \(n-2\)
for (int i = 0; i < n; i++) {
    for (int j = i + 1; j < n; j++) {
        if (deg[i] != deg[j]) continue;
        cp.add(cp.lexicographic(reverse(without(A[i], i, j)), reverse(without(A[j], i, j))));
    }
}

SB-Lex — addOptLex

$$\forall\, 0 \le i < j < n,\ \mathit{deg}_i = \mathit{deg}_j: \quad M_i^{\setminus\{i,j\}} \;\le_{lex}\; M_j^{\setminus\{i,j\}}$$
Size: \(P\) lexicographic constraints (\(n\ge 3\))Arity: \(2(n-2)\)
if (deg[i] != deg[j]) continue;
cp.add(cp.lexicographic(without(A[i], i, j), without(A[j], i, j)));

1.5 Connectivity (upper off-diagonal) — addUpperOffDiagonal

Every vertex except the last has a neighbor with a larger index.

RevLex only, exact for regular sequences only. Posted with OptRevLex only. With a regular sequence any vertex can take any label and the counts are exact. With unequal degrees only equal-degree vertices can swap labels, and some connected graphs have no valid labelling: e.g. \(K_{2,3}\) for \(\mathit{deg} = (2,2,2,3,3)\), where vertex 4 only has neighbors 1, 2, 3. The constraint is posted anyway; for non-regular sequences the counts may be too low (7 of the 144 graphic sequences with \(n \le 6\)).

$$\forall i \in [0, n-1): \quad \sum_{v=i+1}^{n-1} M_{iv} > 0$$
Size: \(n-1\) constraintsArity: \(n-1-i\) for vertex \(i\)
for (int i = 0; i < n - 1; i++) {
    IloIntExpr[] upper = new IloIntExpr[n - 1 - i];
    for (int v = i + 1; v < n; v++) upper[v - i - 1] = A[i][v];
    cp.add(cp.gt(cp.sum(upper), 0));
}

2. Neighbors model (Nei)

2.1 Variables X

Row \(i\) lists the neighbors of vertex \(i\) as labels, in \(D\) slots (the largest degree); the \(D - \mathit{deg}_i\) unused slots hold 0. Example: neighbors \(\{2,5\}\) with \(D=4\) → 2 5 0 0 (RevLex) or its mirror image 0 0 5 2 (Lex).

$$X = \{\, M_{ik} \;:\; 0 \le i < n,\; 0 \le k < D \,\}, \qquad \{v+1 : \{i,v\} \in E\} = \{M_{ik} : M_{ik} \neq 0\}$$
|X| = \(nD\) variables
int D = 1;
for (int d : deg) D = Math.max(D, d);
IloIntVar[][] M = new IloIntVar[n][];
for (int i = 0; i < n; i++) {
    M[i] = cp.intVarArray(D, 0, n);   // 0 = empty slot
    ...
}

2.2 Domains D

$$D(M_{ik}) = \{0, 1, \dots, n\} \qquad (0 = \text{empty slot})$$
|D| = \(n+1\) values per variable
cp.intVarArray(D, 0, n)

2.3 Constraints C (base model, buildNeighborsModel)

Notation: \(\#_a(M_i) = |\{k : M_{ik} = a\}|\) is the number of occurrences of \(a\) in row \(i\) (cp.count(M[i], a)). The base model only describes the graph; the degree and "no repeated neighbor" come from the row layout (2.4).

C1 — No self-loop

$$\forall i \in [0,n),\ \forall k \in [0,D): \quad M_{ik} \neq i+1$$
Size: \(nD\) constraintsArity: 1
for (int k = 0; k < D; k++) cp.add(cp.neq(M[i][k], i + 1));   // no self-loop

C2 — Symmetry (undirected graph)

$$\forall\, 0 \le u < v < n: \quad \#_{v+1}(M_u) = \#_{u+1}(M_v)$$
Size: \(n(n-1)/2\) constraintsArity: \(2D\) (rows \(u\) and \(v\))
for (int u = 0; u < n; u++) {
    for (int v = u + 1; v < n; v++) {
        cp.add(cp.eq(cp.count(M[u], v + 1), cp.count(M[v], u + 1)));   // undirected
    }
}

Each count is 0 or 1 because the row layout makes the neighbors strictly ordered; padding zeros never match since labels are \(\ge 1\).

2.4 Row layout (simple graph) — addLexRows, addRevLexRows

The zeros are fixed by position and the neighbors are strictly ordered: increasing before the zeros for RevLex, decreasing after them for Lex (the mirror image). Together they give exactly \(\mathit{deg}_i\) distinct neighbors per row: no degree count and no all-different are needed, and each neighbor set has a single row.

$$\text{Lex (0 0 5 2):}\quad M_{ik} = 0 \ (k < D-\mathit{deg}_i), \quad M_{i,D-1} \ge 1, \quad M_{ik} > M_{i,k+1} \ (D-\mathit{deg}_i \le k < D-1)$$ $$\text{RevLex (2 5 0 0):}\quad M_{ik} = 0 \ (k \ge \mathit{deg}_i), \quad M_{i,0} \ge 1, \quad M_{ik} < M_{i,k+1} \ (0 \le k < \mathit{deg}_i - 1)$$
Size: \(D\) constraints per row, \(nD\) in total (the "\(\ge 1\)" only when \(\mathit{deg}_i > 0\))Arity: 1 or 2
// addRevLexRows
int D = M[i].length, last = deg[i] - 1;    // last neighbor slot
for (int k = deg[i]; k < D; k++) cp.add(cp.eq(M[i][k], 0));
if (deg[i] > 0) cp.add(cp.ge(M[i][0], 1));
for (int k = 0; k < last; k++) cp.add(cp.lt(M[i][k], M[i][k + 1]));

// addLexRows
int D = M[i].length, first = D - deg[i];   // first neighbor slot
for (int k = 0; k < first; k++) cp.add(cp.eq(M[i][k], 0));
if (deg[i] > 0) cp.add(cp.ge(M[i][D - 1], 1));
for (int k = first; k + 1 < D; k++) cp.add(cp.gt(M[i][k], M[i][k + 1]));

2.5 Symmetry breaking (only pairs of equal degree)

Rebuilt 0/1 rows — adjacencyOf (used by optLexNei, optRevLexNei)

$$C_{iv} = \begin{cases} 0 & v = i \\ \#_{v+1}(M_i) & v \neq i \end{cases} \qquad (C_{iv} = 1 \iff \{i,v\} \in E)$$
Size: no constraint; \(n(n-1)\) count expressions (+ \(n\) constants)Each \(C_{iv}\) reads: \(D\) variables (row \(i\))
A[u][v] = (u == v) ? cp.constant(0) : cp.count(M[u], v + 1);

SB-RevLex / SB-Lex on rebuilt rows — addOptRevLexNei, addOptLexNei

The same constraints as Adj (1.4), posted on \(C\) instead of \(M\).

$$\forall\, i < j,\ \mathit{deg}_i = \mathit{deg}_j: \quad \operatorname{rev}\!\big(C_i^{\setminus\{i,j\}}\big) \le_{lex} \operatorname{rev}\!\big(C_j^{\setminus\{i,j\}}\big) \ \ \text{(RevLex)}, \qquad C_i^{\setminus\{i,j\}} \le_{lex} C_j^{\setminus\{i,j\}} \ \ \text{(Lex)}$$
Size: \(P\) lexicographic constraints (\(n\ge 3\))Arity: \(2D\) variables (rows \(i\) and \(j\)), through two vectors of \(n-2\) count expressions
private static void addOptRevLexNei(IloCP cp, IloIntVar[][] M, int[] deg) throws IloException {
    addOptRevLex(cp, adjacencyOf(cp, M), deg);
}

SB-Dir-RevLex — drop, then RevLex on the rows (addOptRevLexNeiDir)

The same order as SB-RevLex on rebuilt rows, without rebuilding the 0/1 rows. For the pair \((i,j)\): drop label \(j+1\) from row \(i\) and label \(i+1\) from row \(j\) (if found), then compare the two rows from the last slot. Read right to left, the 0/1 rows first differ at the largest vertex \(w\) of \((N(i)\setminus\{j\}) \,\triangle\, (N(j)\setminus\{i\})\), and row \(i \le\) row \(j\) iff \(w \in N(j)\); the rows list the neighbors increasing, so read from the last slot they also first differ at \(w\). The fixed zeros are in the same slots of both rows (equal degrees) and never decide.

$$\forall\, i < j,\ \mathit{deg}_i = \mathit{deg}_j: \quad \operatorname{rev}\!\big(M_i^{-(j+1)}\big) \;\le_{lex}\; \operatorname{rev}\!\big(M_j^{-(i+1)}\big)$$ $$M_i^{-a}[k] = M_{i,k} + t_k\,(M_{i,k-1} - M_{ik}), \qquad t_k = \sum_{m=k}^{D-1} [M_{im} = a] = [k \le p], \qquad M_{i,-1} = 0$$
Size: \(P\) lexicographic constraints (\(n\ge 3\))Arity: \(2D\) variables (rows \(i\) and \(j\)), through two vectors of \(D\) expressions
if (deg[i] != deg[j]) continue;
IloIntExpr[] ri = dropLabel(cp, M[i], j + 1);   // row i without j+1
IloIntExpr[] rj = dropLabel(cp, M[j], i + 1);   // row j without i+1
cp.add(cp.lexicographic(reverse(ri), reverse(rj)));

// dropLabel(cp, row, label): slots before the label move right, 0 enters slot 0
IloIntExpr atOrBefore = cp.constant(0);   // [k ≤ p]
for (int k = D - 1; k >= 0; k--) {
    atOrBefore = cp.sum(atOrBefore, cp.eq(row[k], label));
    IloIntExpr prev = (k > 0) ? row[k - 1] : cp.constant(0);
    out[k] = cp.sum(row[k], cp.prod(atOrBefore, cp.diff(prev, row[k])));
}

\(p\) is the slot holding the label. If it is not found, every \(t_k\) is 0 and the row is unchanged: no adjacency indicator is needed. The 0 enters at the front so that the freed slot is the last one compared (both Lex and RevLex compare from the last slot). Example: 2 5 0 0 without 5 → 0 2 0 0. Finds the same solutions as SB-RevLex on rebuilt rows.

SB-Dir-Lex — drop, then Lex on the rows (addOptLexNeiDir)

The mirror image for OptLex. Read left to right, the 0/1 rows first differ at the smallest vertex \(w\) of the symmetric difference. The Lex rows list the neighbors decreasing (0 0 5 2), so read from the last slot they give the smallest neighbor first and also first differ at \(w\); the row holding \(w\) is the smaller one, hence the swapped arguments. The same dropLabel is used: the freed slot is slot 0, the last one compared. Example: 0 0 5 2 without 5 → 0 0 0 2.

$$\forall\, i < j,\ \mathit{deg}_i = \mathit{deg}_j: \quad \operatorname{rev}\!\big(M_j^{-(i+1)}\big) \;\le_{lex}\; \operatorname{rev}\!\big(M_i^{-(j+1)}\big)$$ $$M_i^{-a} \text{ as in SB-Dir-RevLex (same } \texttt{dropLabel}\text{)}$$
Size: \(P\) lexicographic constraints (\(n\ge 3\))Arity: \(2D\) variables, through two vectors of \(D\) expressions
if (deg[i] != deg[j]) continue;
IloIntExpr[] ri = dropLabel(cp, M[i], j + 1);   // row i without j+1
IloIntExpr[] rj = dropLabel(cp, M[j], i + 1);   // row j without i+1
cp.add(cp.lexicographic(reverse(rj), reverse(ri)));

2.6 Connectivity — addLargestNeighborAbove

RevLex only, exact for regular sequences only, like the Adj version (1.5).

"A neighbor with a larger index" is "the largest neighbor is above \(i+1\)". In the RevLex layout (2 5 0 0) the largest neighbor is the last neighbor slot \(\mathit{deg}_i - 1\). A vertex of degree 0 uses slot 0, which holds 0, so the constraint fails as it should. Used by both optRevLexNei and optRevLexNeiDir; about 3× faster than the count-based sum on 4-regular graphs with \(n = 12\).

$$\forall i \in [0,n-1): \quad M_{i,\ \max(\mathit{deg}_i - 1,\,0)} > i+1$$
Size: \(n-1\) constraintsArity: 1
for (int i = 0; i < M.length - 1; i++) {
    int last = Math.max(deg[i] - 1, 0);   // deg 0: slot 0 holds 0, so the constraint fails
    cp.add(cp.gt(M[i][last], i + 1));
}

4. Models

Each public model method of CpModels builds a base model, posts its row layout and symmetry breaking and, for OptRevLex when connectivity is true, a connectivity constraint; then it enumerates all solutions.

Main runs the 6 models when CONNECTIVITY = false, and only the 3 OptRevLex ones (columns suffixed Con) when CONNECTIVITY = true. Degree sequences come from DEFAULT_SEQUENCES or the command line, and are sorted increasing before they are run.

Checked by brute force on all graphic sequences with \(n \le 6\): the three encodings give the same counts for each order, with and without connectivity, and never lose a graph without connectivity. Restricting the symmetry breaking to equal-degree pairs is sound but not complete: for some non-regular sequences a graph is found more than once.

Solver settings shared by all models (in solve): depth-first search, default inference level Low, quiet log.
